# 翻譯檢核準則（共用指示）

本檔為各章檢核 agent 的共用指示，也是本輪檢核的判準紀錄。

## 任務

逐段比對西班牙文原文與繁體中文譯文，找出問題並產出結構化報告。**絕對不要修改任何譯文檔案**，只產出報告檔。不可抽樣、不可跳過任何段落。

## 共用檔案

- 術語表：`D:\Code\trpg-doc\maho-shojo\glossary.json`（格式：`{"西文術語": {"zh": "譯法", "notes": "...", "status": "...", "forbidden": [...]}}`）
- 風格決策：`D:\Code\trpg-doc\maho-shojo\style-decisions.json`
- 全站譯文（跨章一致性查證用）：`D:\Code\trpg-doc\maho-shojo\docs\src\content\docs\rules\*.md`

## 原文檔的兩種格式

1. **排版稿**：正規 Markdown，標題與譯文一一對應，依標題順序配對即可。
2. **原始萃取稿**：無 Markdown 標題、行中有斷字連字號（如 `pro-\nfundidad`）、夾雜頁碼與頁眉（如 `44`、`Maho Shojo`）。請依內容順序對照譯文的標題結構自行對齊；斷字與頁碼雜訊不算翻譯問題，忽略即可。

各章屬於哪種格式，派遣指示中會註明。

## 四個檢核面向

1. **terminology（詞彙統一）**：譯文中同一西文術語是否全章譯法一致，且符合 glossary.json 的規定譯法（注意 `forbidden` 禁用形）。特別注意遊戲機制詞（Pacto、Talismán、Movimiento、Oscuridad、Luz、Libreto、MC、PJ、Punto 各類點數等）在正文中的每次出現。**回報術語不一致前，必須用 Grep 對全站 rules/*.md 查證哪種譯法是主流**，並在報告中列出佐證行號。
2. **taiwan-usage（台灣用語）**：簡體字殘留；中國用語（如：質量、信息、視頻、網絡、軟件、水平、優先級、屏幕、菜單、默認、設置、紐帶、團隊協作、支持〔作「支援」義〕、通過〔作介詞〕等）；標點須全形（：，。、；「」『』（）……），數字與英文用半形；刪節號用「……」。
3. **fluency（語句流暢）**：翻譯腔——西式長句直譯、「的」連續堆疊、過度被動、「進行／做出＋動詞」冗贅、代詞冗餘、語序不自然。反向也要查：**過度在地化**——華麗成語或典故若西文原文並無對應意涵，須標記（前例：el ancla 誤譯「定海神針」，後改「中樞」）。
4. **fidelity（忠實度）**：逐段比對漏譯（原文有、譯文無的句子或資訊）、增譯（譯文自行添加）、誤譯（意思偏離，注意西文假朋友如 simpatía、condenado、raramente）、語氣偏移（原文建議語氣 vs 譯文命令句）、規則語意偏移（主詞遺失導致規則對象不明、can/must 混淆）。西文第二人稱複數（vosotros，指玩家群）應譯「你們」；動漫作品名應用台灣通行譯名。

## 數字慣例

骰值、點數、數值用阿拉伯數字（「1 點」不是「一點」）；散文中的量詞用中文（一個、兩次、三種）。同章混用視為 A 級。

## 已知全站議題（勿重複回報）

以下議題已記錄待全站統一決策，各章報告**不必**再列，除非該章有特殊變體：

1. 「創建」→「建立／創造」的全站取捨（全站 104 處）。
2. 「主持人（MC）」全稱＋括號每頁重複出現的精簡策略。
3. 各章新創動作／優勢／裝備名稱未入 glossary 的總體建檔策略——但**該章出現的未建檔名稱清單仍須列出**（合併為一筆 B 級），供批次建檔用。

## 分級

- **A 級**：明確錯誤，之後可直接修正——簡體字、標點錯誤、違反 glossary 定論（含禁用形）的術語不一致、明確漏譯、明確中國用語、明確誤譯、數字慣例違規。
- **B 級**：需使用者決策——語感重寫建議、雙關與文化詞、glossary 尚無定論或需變更的術語、可辯論的譯法取捨、原文歧義的詮釋選擇。每筆須附 2–3 個候選方案與簡短理由。
- **C 級**：小建議，可改可不改。

## 報告格式

寫入 `D:\Code\trpg-doc\maho-shojo\reports\translation-review\<章節名>.md`（繁體中文）：

```markdown

## 摘要
- 檢核段落數：N／發現問題：A 級 x 筆、B 級 y 筆、C 級 z 筆

### A1｜<面向>｜<簡短標題>
- 位置：譯文第 123 行（## 章節標題下第 2 段）
- 原文：「…西文摘錄（只引相關句）…」
- 譯文：「…中文摘錄…」

- 建議修法：（直接給出修正後文句）

## B 級（需決策）

### B1｜<面向>｜<簡短標題>

  2. 「方案二」——理由

## C 級（建議）
（同格式，可精簡成條列）
```

- 編號依 A1、A2…、B1…、C1… 排列；嚴重度高者在前。
- 同一問題多處重複（如同一術語不一致）合併為一筆並列出所有行號。
- 「位置」一律以**譯文檔的實際行號**為準（Read 工具讀出的行號）。

回覆：各級問題筆數統計、報告檔路徑、你認為最重要的 3 個發現（一行一個）。不要在回覆中重複完整報告內容。
