# 參考作品分析資料庫

:::caution[劇透警告]
本庫「劇本設計」一節逐一分析各作品的系列構成、敘事結構與關鍵轉折，含完整劇透。
《魔法少女小圓》、《結城友奈是勇者》、《舞-HiME》、《魔法少女網站》尤其嚴重——
這幾部作品的核心體驗建立在敘事轉折之上，「劇本設計」一節會直接寫出轉折內容。
:::

蒐集 Mahō Shōjo 規則書引為參考的魔法少女動畫作品，逐一分析其「作品含意」「設計概念」「劇本設計」三軸，**以日語維基百科條目為主幹來源**，保存原文並完整翻譯成繁體中文。

本資料庫是 `maho-shojo` repo 底下的獨立資料夾，**不併入 Astro 網站**，也不參與規則書的翻譯與術語檢查流程。

## 條目的組成

每個條目是一個 Markdown 檔，frontmatter 記錄 `id`、`title_zh`、`title_native`、`title_romanized`、`title_en`、`year`、`years`、`media`、`origin`、`studio`、`key_staff`、`pact_mapping`、`cited_in`、`source`、`tags`；正文分七節：`## 概要`、`## 作品含意`、`## 設計概念`、`## 劇本設計`、`## 其餘重要脈絡`、`## 專有名詞對照`、`## 來源與授權`。

`origin` 是原作媒體型態；`pact_mapping` 只填規則書 `docs/src/content/docs/rules/pacts.md` **明寫**的對應（光明子女／正義騎士／契約傀儡），規則書未指定者一律 `null`，不自行歸類。

### 三軸

- **作品含意**：作品的主題、母題，作品在說什麼。
- **設計概念**：企劃緣起、製作意圖、角色與美術設計概念、系列在同類型作品中的定位。
- **劇本設計**：系列構成、敘事結構、腳本手法、關鍵轉折的設計。

三軸的每一段非中文材料，都寫成「原文逐字引用（blockquote）＋下方繁體中文譯文」一組，不省略原文。

### 查無材料的寫法

某一軸確實查無可佐證的材料時，該節寫成 `:::note[查證結果]` 區塊，明載實際查過哪些來源（維基全文、官方網站及其存續狀態、其他可檢索的訪談）與查證結果，而不是略過該節或留白。

這是本子庫刻意採取的規範，理由是：**不得以推測填滿三軸**。寫一段看似合理但無來源佐證的分析，是本計畫定義的失敗，比誠實承認查無材料更糟。複審時也曾發現查證結果區塊的記載與實際查證不符的情形（把抓取失敗的空白內容誤記為「該來源已無存檔」），因此區塊裡的每一句狀態都必須對應一份實際讀過、內容非空的存檔，或一次有回應的查詢，讓後續複審能依原始出處覆核，而不是單方面採信。

`tokyo-mew-mew.md` 的「劇本設計」一節是本規範的實例：該條目逐一記錄已讀畢維基全文及三個 2002 年官方網站的典藏頁面後，仍未見製作方對敘事結構的具體說明，因而如實寫成查證結果區塊。

## 來源政策

- 主幹來源是**日語維基百科**條目，授權 **CC BY-SA 4.0**。
- 補強來源是官方網站與製作方訪談，以節錄引用方式收錄，不整篇轉載。
- 官方網站多半已停止維護；失效網站一律改查**網際網路典藏館**（Wayback Machine）的存檔頁面，並在 frontmatter 的 `source.extra[].archived` 標註是否為典藏版本、`retrieved` 記錄擷取日期。

### 引文可查證性的限度

本庫每一則 `>` 原文引文，撰寫當時都是對照 `.cache/` 底下抓回來的頁面純文字逐字比對過的（非維基來源依裁決 H 另存為 `.cache/sources/<id>-<序號>.txt`，檔首三行記標題、URL 與擷取日期）。但 **`.cache/` 列在 `.gitignore` 第 43 行，不隨 repo 發布**，因此這件事有明確的限度，這裡如實寫下：

- **可復原的部分**：每則引文的出處定位資訊——來源標題、發行者或媒體名稱、URL、擷取日期，以及是否為網際網路典藏館的版本——都寫在各條目的「來源與授權」一節。頁面仍在線上時，依這些資訊重新取得後即可再次逐字比對。**這份定位資訊才是本庫耐久的紀錄。**
- **不可復原的部分**：`.cache/` 本身不在版本控制內，clone 下來的人手上沒有本庫撰寫當時的那份副本，無法用「同一份檔案」重跑比對。來源頁面若已下架、改版、移入付費牆或改為需登入，重新取得的內容可能與撰寫當時所見不同，甚至完全取不到；此時該則引文就只剩條目自己的記載，沒有第三方副本可以覆核。
- 維基百科來源可用 `source.retrieved` 的日期回查該日的歷史版本，程度上能還原；非維基來源則未必有對應的典藏版本，`source.extra[].archived` 只記錄本庫取用時是否走典藏館，不保證日後仍查得到。

因此：修改既有條目的引文時，不要假設 `.cache/` 還在或還是原來那一份，先確認手上的快取檔檔首所記的 URL 與擷取日期，與條目「來源與授權」所載相符。

## 與魔女傳說庫的關係

本庫與 `reference/regions/` 等目錄構成的魔女傳說參考資料庫是兩個平行且互相獨立的子庫：

- frontmatter schema 不共用——魔女傳說庫記地區、語系、時代，本庫記年份、原作型態、盟約對應。
- 名詞總表不互相併入——本庫的 `name-glossary.md` 與魔女傳說庫的 `reference/name-glossary.md` 各自獨立，也都不寫入遊戲規則術語庫 `glossary.json`。
- 兩庫皆**不併入 Astro 網站**，也都不參與規則書的翻譯與術語一致性檢查流程。
