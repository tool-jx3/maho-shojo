## 遊戲簡介

Mahō Shōjo 是一款以魔法少女為主題的桌上角色扮演遊戲，使用 PbtA（Powered by the Apocalypse）系統。玩家扮演擁有強大力量的魔法少女，在日常生活中維繫友情與羈絆，同時對抗來自黑暗的威脅。
