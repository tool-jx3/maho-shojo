勇者、參謀與衛士！
鬥士、偶像與聖母！
光明的子女們！

透過 Mahō Shōjo，你和你的夥伴們將能講述少女們的故事——她們心中蘊藏著強大的力量，足以改變周遭的世界。這款桌上角色扮演遊戲將讓你們體驗屬於自己的魔法少女類型故事，就如同漫畫和動畫系列一般。

當你是故事的主角時，一切都會更加美好——對抗逆境、經歷屬於自己的浪漫、享受日常生活中的小小奇蹟……同時還要試著理解你的新力量！

Mahō Shōjo 為你提供：

- 讓你從此類型的經典原型出發、建立專屬魔法少女的指引，以及無數的自訂選項，讓她成為獨一無二的角色。
- 探索角色之間友情與戀愛羈絆的系統，讓她們以扣人心弦的方式投入遊戲。
- 基於此類型專屬敘事動作的遊戲系統，確保每次聚會都充滿活力且風味獨特。
- 建立黑暗使徒的建議與指引，他們將考驗你們魔法少女心中的光明。
- 三種不同的故事取向，反映此類型的主要變體及其演變。
- 無數實用的建議，讓你以最少的心力籌備聚會，收穫精彩的成果。

你會成為正義的騎士，還是黑暗的傀儡？
來玩 Mahō Shōjo，一探究竟。
